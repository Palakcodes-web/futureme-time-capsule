# 💜 FutureMe — Letters Through Time

A beautiful digital time capsule that lets you write letters to your future self and revisit them on a chosen date.

🔗 **Live Website:** https://palakcodes-web.github.io/futureme-time-capsule/

## ✨ Features

- 💌 Write personalized letters to your future self
- ⏳ Countdown to your chosen opening date
- 🔓 Read letters when their scheduled date arrives
- 💾 Save letters in your browser using Local Storage
- 🗑️ Delete saved letters
- 🌌 Dark, starry design with animated elements
- 📱 Responsive layout for different screen sizes

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Browser Local Storage
- GitHub Pages

## 🚀 Run Locally

1. Clone this repository.
2. Open `index.html` in your browser.
3. Create your first time capsule!

No installation is required.

## 📌 How It Works

Write a letter, choose a date, and save it as a time capsule. FutureMe stores your letter in your browser and displays a countdown until its scheduled opening date.

**Note:** Letters are stored locally in your browser, not on a server. They are not automatically synced across devices.
